# ปัญญาบาน · คลังสื่อการเรียนรู้สร้างสรรค์

เว็บคลังสื่อการเรียนรู้ที่ครูพัฒนาขึ้น ทั้งเว็บแอป วิดีโอ ใบความรู้ เกมและแบบฝึก อินโฟกราฟิก และแผนการสอน

พัฒนาโดย นางสาวศิริลักษณ์ ผาเนตร์ ครู สำนักงานส่งเสริมการเรียนรู้ประจำจังหวัดหนองบัวลำภู

## คุณสมบัติ

- ค้นหาสื่อ เลือกตามหมวด เรียงตามใหม่ล่าสุด/ยอดนิยม/ชื่อ และกดดูรายละเอียดพร้อมภาพหน้าปก
- ฟอนต์ Prompt โทนพาสเทล มีโหมดมืด ใช้ได้ทั้งมือถือและคอมพิวเตอร์
- **ระบบผู้ดูแล**: เข้าด้วยรหัสผ่าน แล้วเพิ่ม แก้ไข ลบสื่อ และอัปโหลดภาพหน้าปกได้จากหน้าเว็บ
- **สถิติการเข้าชม** ท้ายหน้า: จำนวนสื่อ การเข้าชมทั้งหมด ผู้เข้าชม และเข้าชมวันนี้

## ไฟล์

```
index.html, styles.css, app.js   หน้าเว็บ
data.js                          ชื่อเว็บ ข้อความหน้าแรก หมวดหมู่ ข้อมูลผู้พัฒนา และสื่อเริ่มต้น
config.js                        URL ของ Apps Script
apps-script/Code.gs              ระบบหลังบ้าน (Google Apps Script)
```

## ขั้นที่ 1: นำขึ้นเว็บ (GitHub Pages)

1. ไปที่ **Settings → Pages** ของ repo นี้
2. หัวข้อ **Source** เลือก **GitHub Actions**
3. ทุกครั้งที่ push เข้า `main` เว็บจะ deploy เองที่ `https://siriluck327.github.io/EDU-NFE/`

ถ้ายังไม่ได้ทำขั้นที่ 2 เว็บจะแสดงสื่อเริ่มต้นใน `data.js` และนับสถิติเฉพาะบนเครื่องของผู้เข้าชมแต่ละคน

## ขั้นที่ 2: เปิดระบบผู้ดูแลและสถิติ (Google Sheets + Drive)

1. สร้าง Google Sheet ใหม่ แล้วไปที่เมนู **ส่วนขยาย → Apps Script**
2. ลบโค้ดเดิม วางโค้ดจาก [`apps-script/Code.gs`](apps-script/Code.gs) แล้วแก้บรรทัด `const ADMIN_PIN = 'CHANGE-ME';` เป็นรหัสผ่านผู้ดูแล จากนั้นกดบันทึก
   (แก้รหัสใน Apps Script เท่านั้น อย่าใส่รหัสจริงในไฟล์ของ repo นี้ เพราะ repo เป็นสาธารณะ)
3. **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → ประเภท: เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
4. กด **ทำให้ใช้งานได้** อนุญาตสิทธิ์ (Google Sheets และ Google Drive) แล้วคัดลอก URL ที่ลงท้ายด้วย `/exec`
5. ใส่ URL ใน [`config.js`](config.js) แล้ว push ขึ้น `main`
6. เปิดเว็บ กด **ผู้ดูแลระบบ** ที่ footer (หรือเปิด `https://siriluck327.github.io/EDU-NFE/#admin`) แล้วใส่รหัสผ่าน

การเข้าสู่ระบบครั้งแรกจะคัดลอกสื่อเริ่มต้นใน `data.js` เข้าแท็บ `Media` ของ Sheet ให้ หลังจากนั้นกด **+ เพิ่มสื่อใหม่** หรือ **แก้ไข / ลบ** บนการ์ดได้เลย ภาพหน้าปกจะถูกย่อขนาดในเบราว์เซอร์และเก็บในโฟลเดอร์ `คลังสื่อ - รูปภาพ` ใน Google Drive (แชร์แบบทุกคนที่มีลิงก์ดูได้) ถ้าใส่รหัสผิด 10 ครั้ง ระบบจะล็อกไว้ 10 นาที

ถ้าแก้ `Code.gs` ภายหลัง ต้องไปที่ **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** ทุกครั้ง

## ปรับแต่ง

- ชื่อเว็บ ข้อความหน้าแรก และข้อมูลผู้พัฒนา: แก้ `site` และ `owner` ใน `data.js`
- หมวดหมู่: แก้ `categories` ใน `data.js` (สีเลือกได้จาก lavender, mint, peach, sky, butter, pink และห้ามเปลี่ยน `id` ของหมวดที่มีสื่ออยู่แล้ว)

## ทดลองบนเครื่อง

